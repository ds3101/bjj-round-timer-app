# Auto-Push to GitHub
Whenever you successfully make code changes, implement a feature, or fix a bug in this workspace, you MUST automatically commit those changes and push them to GitHub. 

Use the `run_command` tool to run the following before finishing your task:
```bash
git add .
git commit -m "Auto-commit: <brief summary of changes>"
git push
```
Do not ask the user for permission to push unless the operation fails.
